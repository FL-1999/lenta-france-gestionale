## Assistente personale

Il canale dedicato all'assistente è disattivato per impostazione predefinita.
Configurazione, API e conferma delle operazioni sono descritte nella
[guida dell'integrazione](docs/assistant-integration.md).

## Check marker di conflitto Git

Esegui il check automatico per assicurarti che non siano presenti marker di conflitto Git nei file versionati:

```bash
python scripts/check_conflict_markers.py
```
